# Курьер кампуса — браузерный платформер

Практическое задание № 3. Игра сделана на HTML, CSS и обычном JavaScript (ES-модули), без игровых движков, npm и сборки.

## Как запустить

1. Скачайте и распакуйте архив проекта.
2. Откройте папку `platformer_game` в Visual Studio Code.
3. Для запуска используйте расширение **Live Server**: нажмите правой кнопкой по `index.html` → **Open with Live Server**.
4. Также можно открыть `index.html` в браузере, если браузер разрешает загрузку ES-модулей с локального файла. Если модули не загружаются, используйте Live Server.

## Управление

- `A` / `D` или `←` / `→` — движение.
- `Space` или `W` / `↑` — прыжок.
- На телефоне предусмотрены экранные кнопки управления.
- Кнопки интерфейса: старт/продолжить, пауза, заново.

Прыжок доступен только тогда, когда персонаж стоит на платформе. Уровень содержит пять приподнятых платформ, безопасные участки земли, три пропуска, опасную зону и финиш. Для победы нужно собрать все три предмета и коснуться финиша.

## Структура проекта

```text
platformer_game/
├── index.html
├── style.css
├── README.md
└── js/
    ├── main.js
    ├── Game.js
    ├── Player.js
    ├── input.js
    └── collision.js
```

- `index.html` — разметка страницы, HUD, Canvas, кнопки.
- `style.css` — оформление интерфейса и адаптация под мобильные экраны.
- `main.js` — связывает интерфейс и игровую логику, запускает единый `requestAnimationFrame`.
- `Game.js` — состояние игры, уровень, предметы, счёт, победа/поражение, отрисовка.
- `Player.js` — персонаж, скорость, гравитация, прыжок и отрисовка.
- `input.js` — клавиатура и сенсорные кнопки.
- `collision.js` — пересечения и столкновения с платформами.

- [x] Стрелки/A–D и Space/W; повторный прыжок в воздухе запрещён.
- [x] Гравитация и столкновения с платформами.
- [x] Счёт, сбор предметов, победа и поражение.

## Проверка перед сдачей

1. Пройдите уровень, собрав три пропуска и коснувшись финиша.
2. Проверьте поражение при падении в опасную зону.
3. Нажмите паузу, затем продолжить.
4. Нажмите «Заново» пять раз подряд и убедитесь, что скорость игры не меняется.
5. Переключитесь на другую вкладку и вернитесь — игра должна быть на паузе.
6. Обновите страницу и проверьте сохранённый рекорд.
7. Проверьте клавиатуру и экранные кнопки на мобильном устройстве.
